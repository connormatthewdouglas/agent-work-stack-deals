Plan an agent stack

Describe the agent you're building. A keyword parse (no AI model) maps it to components (GPU, scraping, proxies, search API, LLM API, email, hosting, database, monitoring) and shows the cheapest option with a cited price among tracked providers. Where no tracked vendor publishes a price, it says no sourced price tracked. Vendors we don't track may cost less. Referral links are labelled and never affect ranking. Data as of 2026-10-29 (newest price check in the data).
