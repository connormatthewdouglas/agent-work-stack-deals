Cost to fine-tune a 7B or 8B model (LoRA, e.g. Llama 3.1 8B)

This is a job-cost calculator, not a claim that a named fine-tune takes a fixed number of hours. It complements the fixed-hour tables on GPU rental cost by hours (10, 100, or 730 GPU-hours) and the GPU cost calculator. Rates below are the cheapest single-GPU on-demand figures among tracked providers in the week-of-Nov-23 snapshot (feed last updated Nov 28, 2026, 4:17 AM ET (2026-11-28 09:17 UTC)).

Formula (GPU-hour compute subtotal only): cost = job_hours × GPUs × hourly rate. Every worked example here uses 1 GPU and the stated hour count.

Assumptions (read these first)

  • Hours are examples, not a measured Llama 3.1 8B run. Time to LoRA fine-tune a 7B or 8B model depends on dataset size, sequence length, epochs, batch size, LoRA rank, precision, and the framework. This page does not have a sourced hour count for a specific official recipe, so it does not invent one. Plug in your own hour count, or use the worked rows at 2, 4, 8, and 24 hours.
  • One GPU, on-demand, continuous. Examples ignore spot preemption, queue time, and multi-GPU setups. If you use two GPUs for eight wall-clock hours, the compute subtotal is 8 × 2 × rate.
  • GPU-hour price only. Storage, dataset egress, checkpoints, extra vCPU/RAM, and taxes are not included. The MCP tool flags those as missing costs.
  • "Cheapest" means cheapest among tracked providers, not the whole market. The 80 GB A100 column uses a referral rate (marked below). The 40 GB and 80 GB A100 columns are different products.
  • Rates are from the snapshot dated Nov 28, 2026, 4:17 AM ET (2026-11-28 09:17 UTC). Each rate's own price date is listed with its source. Confirm the vendor page before you spend.

Get these prices from the MCP server

Copy-paste install (no API key). More clients are on the Install (MCP) page. The hosted URL's ?ref= tag only marks which snippet was used.

Hosted endpoint (Streamable HTTP):

claude mcp add --transport http lantern-works-deals https://lantern-works-mcp.lantern-works.workers.dev/mcp?ref=seo-batch1

Local (stdio, via uvx):

claude mcp add lantern-works-deals -- uvx lantern-works-deals-mcp

You can also run uvx lantern-works-deals-mcp as the local command, or add the hosted URL https://lantern-works-mcp.lantern-works.workers.dev/mcp in any MCP client.

Example call: estimate an 8-hour H100 job

After install, call estimate_job_cost with { "gpu_family": "H100", "gpus_per_job": 1, "job_hours": 8, "allow_interruptible": false }. The tool returns a compute subtotal among tracked providers, with assumptions, missing costs (storage, egress, and similar), sources, and a re-openable quote. This page's 8-hour H100 PCIe example uses the same hour count and the Hyperstack on-demand rate from the snapshot, which is $20.00. For an L40S quote, pass gpu_family as L40S instead. job_hours is wall-clock duration per job, not a total of GPU-hours across many GPUs; eight hours on one GPU is job_hours: 8 and gpus_per_job: 1.

JSON without an MCP client: gpu-prices.json, history.json, and the API docs.

Verified-on dates are each offer's own verified_at; offers without one are marked unverified. Affiliate links are marked and use rel="sponsored"; public/non-affiliate badges mark free tiers and vendor-published coupons (no invented codes).
