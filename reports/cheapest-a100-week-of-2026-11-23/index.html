Scope, sources, and license

  • Times labelled ET are America/New_York (UTC-5 on these dates).
  • "Cheapest" means cheapest among tracked providers, not the whole market.
  • GPU-hour price only: excludes storage, data egress, extra vCPU/RAM, and taxes. Confirm those on the vendor page before you spend.
  • On-demand and spot/community are listed separately and are not mixed in the headline ranking. Reserved/commitment and serverless rows are listed only as notes, and are excluded from the cheapest on-demand and cheapest spot figures. Marketplace listings are also separated and labelled.
  • Single-GPU, per GPU-hour unless a row is labelled with a multi-GPU minimum.
  • Each row cites the vendor source_url and that row's own price date (verified_at). A price can change after it was checked.
  • This page uses the live ranked feed at snapshot time. Held-stale records (prices not currently ranked) are omitted. A vendor may still appear here on other live SKUs.
  • History for the week comes from the daily snapshots in history.json (6 snapshots, 2026-11-23 through 2026-11-28). The calendar week of Nov 23 continues through 2026-11-29; this snapshot stops at the Nov 28 feed.
  • Some links are referral links (marked in the tables). Lantern Works may earn a commission if you sign up through them. That never changes the price you pay, and affiliate status is not a ranking factor. See the affiliate disclosure.

Get these prices from the MCP server

Copy-paste install (no API key). More clients are on the Install (MCP) page. The hosted URL's ?ref= tag only marks which snippet was used.

Hosted endpoint (Streamable HTTP):

claude mcp add --transport http lantern-works-deals https://lantern-works-mcp.lantern-works.workers.dev/mcp?ref=seo-batch1

Local (stdio, via uvx):

claude mcp add lantern-works-deals -- uvx lantern-works-deals-mcp

You can also run uvx lantern-works-deals-mcp as the local command, or add the hosted URL https://lantern-works-mcp.lantern-works.workers.dev/mcp in any MCP client.

Example call: cheapest tracked A100 on-demand rates

After install, call compare_gpu_prices with { "gpu": "A100", "on_demand_only": true }. To include labelled spot and community rows, pass on_demand_only as false.

JSON without an MCP client: gpu-prices.json, history.json, and the API docs.
