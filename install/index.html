GPU price monitor for your agent

GPU price comparison for agents, checked daily. Free, read-only MCP server (uvx lantern-works-deals-mcp, version 0.3.27); compare_gpu_prices is the main tool. Rate and provider counts change daily: see the live feed. Some result links are referral links.

Know when GPU prices move. Lantern Works re-reads every tracked GPU rental rate daily from the vendor's own pricing page. Your agent can check what moved since yesterday and act on it, every day, with no API key:

  • /api/v1/gpu-price-changes.json: rates that went down, up, newly tracked or dropped out between the last two daily snapshots, each with the vendor's source page (RSS).
  • compare_gpu_prices(gpu="H100", include_history=true): today's cheapest rates among tracked providers plus each rate's price history and recent changes.
  • GPU price monitor example: a zero-dependency script that alerts when a tracked rate drops by a set percent. Run it on a daily cron.

Hosted endpoint (no install)

The same 8 read-only package tools plus 4 hosted-only opt-in price-watch tools (create_watch_key, watch_price, list_watches, delete_watch; 12 tools in all) over streamable HTTP, served from a free Cloudflare Worker: https://lantern-works-mcp.lantern-works.workers.dev/mcp. It counts calls only as anonymous totals per tool per day (no IPs, user agents or arguments), published at /stats. The ?ref= tag below just records that the link came from this page (counts at /stats.json).

claude mcp add --transport http lantern-works-deals https://lantern-works-mcp.lantern-works.workers.dev/mcp?ref=install

Claude Desktop / Cursor / VS Code ("type": "http" or "url" server): https://lantern-works-mcp.lantern-works.workers.dev/mcp?ref=install

Price-drop webhooks (hosted only, free, opt-in)

The hosted endpoint also has four opt-in tools for GPU price alerts. Call create_watch_key with a public https webhook URL (email optional, contact only, nothing is mailed); it returns an api_key and a webhook_signing_secret once. Then watch_price(gpu="H100", max_hourly_usd=2.0) (optional region, kinds of down/up/new), list_watches and delete_watch, passing api_key or an Authorization: Bearer header. After each daily refresh, matching changes are POSTed to your webhook, at most once per watch and event (X-Lantern-Event-Id is the dedupe key), with X-Lantern-Signature: t=<unix>,v1=<HMAC-SHA256(secret, "t.body")>. Stored for this opt-in only: a hash of the key, the webhook URL, the optional email, your watches and per-key daily counts (never call arguments otherwise). The local server has no keys and no watches.

LlamaIndex

Uses pip install llama-index-tools-mcp (LlamaIndex MCP docs). This uses the hosted endpoint; for the local server use BasicMCPClient("uvx", args=["lantern-works-deals-mcp"]):

import asyncio
from llama_index.tools.mcp import BasicMCPClient, McpToolSpec

async def main():
    client = BasicMCPClient("https://lantern-works-mcp.lantern-works.workers.dev/mcp?ref=install")
    tools = await McpToolSpec(client=client).to_tool_list_async()
    print([t.metadata.name for t in tools])
    print(await client.call_tool("compare_gpu_prices", {"gpu": "H100"}))

asyncio.run(main())

Tested 2026-10-29: both clients listed all 8 package tools (history: tested on version 0.3.23; current version 0.3.27) and compare_gpu_prices returned live rates.

Open WebUI

Open WebUI 0.6.31+ connects to MCP servers over streamable HTTP (Open WebUI MCP docs). As an admin: Settings → Admin → Integrations → External Tool Servers → + Add Connection, set Type to MCP (Streamable HTTP) (not OpenAPI), Server URL:

https://lantern-works-mcp.lantern-works.workers.dev/mcp?ref=install

No auth is needed. To run the local server instead, bridge it with mcpo and add http://localhost:8000 as an OpenAPI connection:

uvx mcpo --port 8000 -- uvx lantern-works-deals-mcp

Tested 2026-10-29: the hosted URL answers MCP tools/list with all 8 package tools (history: tested on version 0.3.23; current version 0.3.27) plus 4 hosted-only watch tools; through mcpo all 8 package tools (history: tested on version 0.3.23; current version 0.3.27) appeared as OpenAPI routes and compare_gpu_prices returned rates. If mcpo fails to start with an import or ssl_certfile error, a dependency release broke it; uvx --with "mcp<2" --with "fastapi<0.120" mcpo … worked.

Privacy and telemetry

Telemetry is off by default. Setting LANTERN_TELEMETRY=1 in the server's environment opts in to an anonymous count of tool calls, sent at most once a day. Each count is only the tool name, package version, UTC day and number of calls. No arguments, IDs or IPs are sent or stored, and telemetry never blocks a tool call. Details: PRIVACY.md.
