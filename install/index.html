GPU price monitor for your agent

GPU price comparison for agents, checked daily. Free, read-only MCP server (uvx lantern-works-deals-mcp, version 0.3.10); compare_gpu_prices is the main tool. Rate and provider counts change daily: see the live feed. Some result links are referral links.

Know when GPU prices move. Lantern Works re-reads every tracked GPU rental rate daily from the vendor's own pricing page. Your agent can check what moved since yesterday and act on it, every day, with no API key:

  • /api/v1/gpu-price-changes.json: rates that went down, up, newly tracked or dropped out between the last two daily snapshots, each with the vendor's source page (RSS).
  • compare_gpu_prices(gpu="H100", include_history=true): today's cheapest rates among tracked providers plus each rate's price history and recent changes.
  • GPU price monitor example: a zero-dependency script that alerts when a tracked rate drops by a set percent. Run it on a daily cron.
uvx lantern-works-deals-mcp

Add Lantern Works to your agent

Free, read-only, no API key. MCP server: lantern-works-deals-mcp (PyPI, MIT; MCP Registry io.github.connormatthewdouglas/lantern-works-deals). Needs uv (or pipx). Tools: compare_gpu_prices, get_price_changes, optimize_stack, optimize_agent_stack, search_deals, compare_deals, get_deal.

Tested 2026-10-29: a clean uvx lantern-works-deals-mcp (0.3.10) initializes over stdio and all 7 tools return results.

Any MCP client (generic)

Command uvx, args ["lantern-works-deals-mcp"], transport stdio. pipx: pipx run lantern-works-deals-mcp. Docker: build the repo's Dockerfile and run docker run -i --rm <image>. Optional env: LANTERN_DEALS_FILE, LANTERN_GPU_PRICES_FILE (offline JSON).

The server only fetches the two public JSON files below and sends User-Agent: lantern-works-deals-mcp/<version>, nothing that identifies you.

Framework examples

  • LangGraph / LangChain: cheapest H100 via langchain-mcp-adapters (tool called directly, no LLM key needed)
  • CrewAI: cheapest GPU for a described job via MCPServerAdapter (direct tool path tested; LLM agent path untested)
  • OpenAI Agents SDK: cheapest GPU for a described job via MCPServerStdio (direct tool path tested; LLM agent path untested)
  • Stack optimizer (OpenAI Agents SDK): describe an agent's job and get the cheapest cited stack via optimize_agent_stack (direct tool path tested; LLM agent path untested). Browser version: /stack/
  • GPU price watcher: prints tracked GPU price moves since a date via get_price_changes, each with the vendor source URL, plus a sample cron line (0.3.8+)
  • GPU price monitor: zero-dependency script that alerts when a tracked rate drops by a set percent, using the price history API

Some tool results include referral links (affiliate: true, redeem_url). source_url is the vendor's own pricing page.

Privacy and telemetry

Telemetry is off by default. Setting LANTERN_TELEMETRY=1 in the server's environment opts in to an anonymous count of tool calls, sent at most once a day. Each count is only the tool name, package version, UTC day and number of calls. No arguments, IDs or IPs are sent or stored, and telemetry never blocks a tool call. Details: PRIVACY.md.
