Add Lantern Works to your agent

Free, read-only, no API key. MCP server: lantern-works-deals-mcp (PyPI, MIT; MCP Registry io.github.connormatthewdouglas/lantern-works-deals). Needs uv (or pipx). Tools: search_deals, compare_deals, get_deal, compare_gpu_prices.

Tested 2026-10-27: a clean uvx lantern-works-deals-mcp (0.2.0) initializes over stdio and all 4 tools return results.

Claude Code

claude mcp add lantern-works-deals -- uvx lantern-works-deals-mcp

Claude Desktop

Settings → Developer → Edit Config (claude_desktop_config.json):

{
  "mcpServers": {
    "lantern-works-deals": {
      "command": "uvx",
      "args": [
        "lantern-works-deals-mcp"
      ]
    }
  }
}

Restart Claude Desktop. If uvx isn't on Claude's PATH, use the absolute path from which uvx.

Cursor

One-click install, or add the same JSON to ~/.cursor/mcp.json / .cursor/mcp.json.

VS Code (Copilot agent mode)

Install in VS Code, or .vscode/mcp.json:

{
  "servers": {
    "lantern-works-deals": {
      "type": "stdio",
      "command": "uvx",
      "args": [
        "lantern-works-deals-mcp"
      ]
    }
  }
}

Skills-based agents (Claude Code skills, OpenClaw)

npx skills add connormatthewdouglas/agent-work-stack-deals

Installs SKILL.md (checked 2026-10-27 with -a claude-code). For OpenClaw MCP, use the generic stdio config below.

Any MCP client (generic)

Command uvx, args ["lantern-works-deals-mcp"], transport stdio. pipx: pipx run lantern-works-deals-mcp. Docker: build the repo's Dockerfile and run docker run -i --rm <image>. Optional env: LANTERN_DEALS_FILE, LANTERN_GPU_PRICES_FILE (offline JSON).

The server only fetches the two public JSON files below and sends User-Agent: lantern-works-deals-mcp/<version>, nothing that identifies you.

No MCP? Use the JSON

  • Deals: https://thelanternworks.com/api/v1/deals.json
  • GPU prices: https://thelanternworks.com/api/v1/gpu-prices.json

More: For agents (endpoints, schema, offer types).

Verified-on dates are each offer's own verified_at; offers without one are marked unverified. Affiliate links are marked and use rel="sponsored"; public/non-affiliate badges mark free tiers and vendor-published coupons (no invented codes).
