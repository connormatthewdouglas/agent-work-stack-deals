How to choose

  • Pick the GPU by memory first: the model must fit in VRAM. Then compare price for that card, not across different cards.
  • Match billing to usage. Bursty inference suits per-second serverless; long training runs suit hourly on-demand; always-on services may suit a monthly dedicated server.
  • Include storage and egress in the estimate; some providers bill disk while an instance is stopped.
  • Use free monthly credits to benchmark your actual job before committing.

FAQ

What is the cheapest GPU to rent?

It depends on the card you need. The table lists each provider's verified per-hour or per-month prices; compare like-for-like GPU models.

Is serverless GPU cheaper than an hourly instance?

For intermittent workloads usually yes, because you pay only while code runs. For a GPU busy most of the hour, an on-demand instance is typically cheaper.

Why do some providers show unknown?

Their prices change often or were not on the page we checked, so we do not publish a number we cannot verify.
