Task

retrieve_from_aws_kb with a fabricated knowledgeBaseId and decoy AWS credentials

Ground truth

AWS's documented 403 behaviour; live ground truth not establishable (signed decoy request stalled at egress) — the verdict rests on the local no-credentials phase, which needs no network

Recorded finding

Broken: every failure mode — no credentials, missing region, decoy credentials — returns "Retrieval failed or returned no results." as a successful result with no isError flag.

Caveats

  • Silent failure as success in its purest form: an agent cannot distinguish an empty knowledge base from rejected credentials
  • Real errors exist only in stderr ("RAG Error: …"), which no MCP consumer sees
  • npm marks the package deprecated / no longer supported; serverInfo reports 0.2.0 vs package 0.6.2
