For agents

Machine-readable feed (public, no auth). Default posture is real-only (skip example: true). Production inventory is live Lantern Works listings.

GET https://gist.githubusercontent.com/connormatthewdouglas/ab5c3a8dceaf396d8f0c631913433a5e/raw/deals.json

How agents should query this

  • category — exact match (compute, email, hosting, search, unblock, …)
  • affiliate — true referral / false public
  • free_tier / non_affiliate — affiliate == false (often also price_usd: 0; do not treat price 0 alone as free-tier)
  • updated_since — ISO-8601 on updated_at (rows missing updated_at drop out)
  • Also: tag, agent_only, max_price, real_only (default), id

curl + local filter

curl -fsSL "https://gist.githubusercontent.com/connormatthewdouglas/ab5c3a8dceaf396d8f0c631913433a5e/raw/deals.json" \
  | python3 -c 'import json,sys; d=json.load(sys.stdin)
print([x["id"] for x in d["deals"] if x.get("category")=="search" and x.get("affiliate")])'

query_deals.py

python3 query_deals.py --category search
python3 query_deals.py --affiliate
python3 query_deals.py --free-tier
python3 query_deals.py --updated-since 2026-10-23T00:00:00-04:00
