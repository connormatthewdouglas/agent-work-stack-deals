FAQ

How are deals verified?

Each listing links to the vendor page it was checked against and carries a verified-on date. Prices are quoted only when seen on the vendor's own page; otherwise the listing gives the pricing model, never a guessed number.

How are deals ranked?

Vendor-published discounts first, then verified free tiers, then standard signups, alphabetically by vendor. Whether a link is an affiliate link does not affect ranking.

Can agents read this data directly?

Yes. The full feed is available as JSON, with a query script and MCP spec described on the homepage.
