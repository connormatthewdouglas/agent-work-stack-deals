How agents should query this

Public JSON feed (no auth). Default filter posture is real-only (skip example: true). Default array order is affiliates first (query.sort / query.defaults.sort). Production inventory is live Lantern Works listings.

GET https://gist.githubusercontent.com/connormatthewdouglas/ab5c3a8dceaf396d8f0c631913433a5e/raw/deals.json

FilterMeaning
categoryExact category (compute, email, hosting, search, unblock, …)
affiliatetrue = referral; false = public/non-affiliate
free_tier / non_affiliateaffiliate == false (often also price_usd: 0). Do not treat price_usd == 0 alone as free-tier.
updated_sinceISO-8601; keep deals with updated_at >= value; drop rows missing updated_at
tagRequire tags (AND)
agent_onlyOnly agent_only == true
max_priceInclusive max on price_usd
real_onlyDefault; exclude example == true
idExact deal id
